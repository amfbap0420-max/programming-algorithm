# フローチャートパズル

高校「情報Ⅰ」のプログラムの基本構造（順次・分岐・反復）を、フローチャートの記号ブロックをはめて学ぶWebアプリです。

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。

1. 上のタブで構造の種類（順次構造・分岐構造・反復構造・組み合わせ・日常生活）を選ぶ
2. 右（スマホでは下）のブロックを選び、図の「ここに置く」をタップ（ドラッグでも置けます）
3. 「答え合わせ」で確認。まちがえた場所は「記号の形」と「中身」のどちらが違うかを表示
4. 正解すると「動きを確かめる」で1ステップずつ実行し、変数の値と表示内容を確認できる

## 使っている記号

端子（開始・終了）、処理、判断、ループ端（始め・終わり）、線・矢印

## 問題（全18問）

- 順次構造：長方形の面積／消費税込みの値段／2つの変数の値の交換
- 分岐構造：合格かどうかの判定／偶数か奇数か／絶対値を求める
- 反復構造：あいさつを5回／1から10までの合計／目標金額まで貯金
- 組み合わせ：偶数だけの合計／合格者の人数／いちばん大きい数／3の倍数は★
- 日常生活：おなかがすいたとき／天気に合わせた登校／自動販売機で飲み物を買う／カップラーメンを作る／横断歩道をわたる

クリアした問題の記録は、ブラウザの localStorage に保存されます。
