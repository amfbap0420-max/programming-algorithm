# 2-3木シミュレーター

2-3木の挿入・削除・検索を1ステップずつ可視化するWebアプリです。

## 使い方
`index.html` をブラウザ（Chrome / Edge など）で開くだけで動きます。サーバーは不要です。

- 数を入れて「挿入」「削除」「検索」（`6, 18, 5` のようにまとめて入力も可）
- ◀ ▶ ボタンまたは ← → キーでステップ移動、「自動再生」で切り替え
- 「元に戻す」で直前の操作を取り消し

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` | 画面のHTML |
| `style.css` | 見た目（ライト/ダークモード対応） |
| `tree23.js` | 2-3木のアルゴリズム本体（`Tree23` クラス：insert / search / remove） |
| `app.js` | SVG描画・ステップ再生・ボタン操作 |
| `test.js` | ランダム操作で2-3木の性質を確かめるテスト（`node test.js`） |

## アルゴリズムの要点
- **挿入**: 葉まで降りてキーを追加。キーが3つになったら真ん中を親へ押し上げて分割し、根まで繰り返す（根が分割されると高さ+1）。
- **削除**: 内部ノードのキーは後者（右部分木の最小キー）と入れ替えて葉から削除。葉が空になったら、兄弟にキーが2つあれば借り、なければ親のキーを下ろして合体（根が空になると高さ-1）。
